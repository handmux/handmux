# Trusted device and address protection

## English

**Layered authentication and clearer protection controls for safer remote access.**

### Added

- 🔐 **Trusted device protection** — add, name, authorize, expire, and revoke browsers from Web or CLI; Token remains required as the first factor.
- 🌐 **Trusted address protection** — manage trusted access addresses and authorize new addresses with clear guidance.

### Changed

- 🛡️ **Clearer authentication controls** — view and enable both protection layers with clear authorization scope and disable-risk guidance.

### Fixed

- 🧾 **Clearer provider feedback** — correct DeepSeek overdue balances.

- 🛡️ **认证控制更清晰** —— 查看并开启两层保护，明确授权范围和关闭风险。
